# CHINO'S TASCA CHINGARO — Demo Walkthrough

Sitio demo completo para la cantina de la familia Guzman.

## Estructura
- `index.html` — landing (hero, nosotros, menú resumen, cantina, galería, contacto, stack)
- `menu.html` — carta completa
- `reservas.html` — formulario de reserva + confirmación
- `contacto.html` — contacto + formulario
- `admin.html` — dashboard demo (KPIs, pedidos, inventario)
- `css/style.css` — paleta auténtica + oro
- `js/main.js` — interacciones

## Flujo demo (start to end)
1. Abre `index.html` → hero con shimmer dorado, marquee de platillos.
2. Scroll → nosotros (banner Guzman), menú resumen, cantina, galería, stack de 10 tools.
3. Clic "Menú" → `menu.html` carta completa por categorías.
4. Clic "Reservar" → `reservas.html` → llena form → confirmación.
5. Clic "Contacto" → `contacto.html`.
6. Abre `admin.html` → dashboard con KPIs, pedidos, inventario bajo.

## Paleta
- Chili rojo `#e63946` · Oro `#e9c46a` · Jade `#2a9d8f` · Negro `#0a0a0a` · Crema `#f5f0e6`

## Ejecutar
Abre `index.html` en el navegador. Sin build, sin dependencias (Tailwind via CDN no usado; CSS puro).
